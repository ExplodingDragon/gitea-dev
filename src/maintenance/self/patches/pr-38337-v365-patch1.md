## 数据结构与方言处理

Codespace 运行时 UUID 在 Manager 开始创建操作前允许为空，非空后需要全局唯一。SQLite、MySQL 和 PostgreSQL 使用来源实现的唯一索引，SQL Server 使用带 `uuid <> ''` 条件的唯一索引，使多个排队记录可以同时保持空 UUID。

默认 Dev Container 模板与表创建属于同一基础迁移，使新安装和从分叉点升级得到相同初始配置。

**实现验收点**

- SQLite 迁移测试和 Codespace 运行时 UUID 唯一约束测试通过。
- SQL Server 分支只约束非空 UUID。
- 基础迁移执行后默认 Dev Container 模板存在。

## 数据结构与升级行为

迁移建立五张表：

- `pages_site`：保存仓库站点开关、发布来源、当前版本、保留数量和同步时间；
- `pages_version`：保存成品摘要、来源、注释、长期保留标记和创建时间；
- `pages_instance`：保存 Pages 实例、令牌摘要、公开根地址和通信状态；
- `pages_domain`：保存自定义域名、验证状态和释放状态；
- `pages_instance_site`：保存每个实例对站点版本的应用结果。

分叉点数据库版本 365 会先执行 Codespace 365，再执行 Pages 366 和注册令牌 367。明确来自 Codespace PR 的数据库版本 366 会从本项继续。Pages PR 单独建立的版本 366 具有不同含义，转入 `self` 时从进入该 PR 前的备份按 `self` 序列升级。

**实现验收点**

- 五张 Pages 表由 `AddPagesTables` 建立。

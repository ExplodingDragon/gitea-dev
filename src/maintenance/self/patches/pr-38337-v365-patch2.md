# Codespace PR #38337：来源迁移 365 patch2

## 来源与执行位置

本项来自 Codespace 提交 `3fc98fc1c089092a2d77978f8d070fe595f595f2`，它为最初来源迁移 365 增加 Manager 注册令牌表。self 的迁移 365、366 当时已经发布，因此该增量实际注册为迁移 367，完成后数据库版本为 368。

## 表结构与升级行为

迁移建立 `codespace_manager_registration_token`，保存唯一注册令牌、用户作用域、有效状态和创建更新时间。`user_id=0` 表示站点作用域，正数表示用户作用域。使用结构同步可以在表已存在时再次确认结构。

**实现验收点**

- 表包含 `id`、`token`、`user_id`、`is_active`、`created`、`updated`。
- `token` 有唯一索引，`user_id` 有普通索引。
- 直接测试连续执行迁移并验证重复令牌被数据库拒绝。

## 当前维护关系

当前 Codespace PR 的完整 `v370.go` 已包含这张表，但现有 self 数据库早在版本 368 就完成了该增量。继续保留 patch2 可以同时服务旧 self 升级和全新 self 迁移序列，不需要重复执行当前 PR 的完整迁移。

**实现验收点**

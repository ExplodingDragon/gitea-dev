数据结构

迁移建立以下五张表：

  • pages_site：保存仓库站点开关、发布来源、当前版本、保留数量和同步时间；
  • pages_version：保存仓库成品摘要、来源、注释、长期保留标记和创建时间；
  • pages_instance：保存 Pages 实例、令牌摘要、公开根地址和通信状态；
  • pages_domain：保存仓库自定义域名、验证状态和释放状态；
  • pages_instance_site：保存每个实例对站点版本的应用结果。

这些表共同支持 Gitea 管理版本历史和目标状态，Pages 实例报告实际部署结果。迁移编号变化只安排执行位置，不改变模型职责。

升级行为

分叉点数据库版本 365 会先执行 Codespace 365，再执行本项。明确来自 Codespace PR 的数据库版本 366 直接执行本项并推进到 367。Pages PR 单独建立的版本 366 已把迁移 365 解释为 Pages，与 self 的编号含义不同，因此使用进入 Pages PR 前的备份按 self 顺序升级。

Codespace PR #38337：来源迁移 365 patch2

来源与执行位置

本项来自提交 3fc98fc1c089092a2d77978f8d070fe595f595f2，该提交在 Codespace 来源迁移 365 中增加 Manager 注册令牌表。因为 self 的迁移 365 和 366 当时已经发布，这项增量实际注册为 self 迁移 367，完成后数据库版本为 368。

文件名保持 pr-38337-v365-patch2.go，用于说明它是 PR #38337 对来源迁移 365 的第二项数据库变化，而不是把实际执行编号写进文件名。

实现验收点

  • AddCodespaceManagerRegistrationTokenTable 注册为 self 迁移 367。
  • 文件名中的来源编号为 365，映射文档中的实际编号为 367。
  • 上一版 self 完成该迁移后的数据库版本为 368。

表结构与升级行为

迁移建立 codespace_manager_registration_token，包含主键、唯一注册令牌、用户作用域、有效状态和创建更新时间。user_id=0 表示站点作用域，正数表示用户作用域。迁移使用 Sync，可在表已经存在时重复确认结构。

实现验收点

  • 表包含 id、token、user_id、is_active、created、updated。
  • token 有唯一索引，user_id 有普通索引。
  • 直接测试连续执行两次迁移并验证重复令牌产生数据库错误。

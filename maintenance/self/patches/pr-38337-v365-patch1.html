数据结构与方言处理

迁移建立 Codespace、Manager、模板、用户密钥、仓库密钥关联、权限授权及相关关联表。Codespace 运行时 UUID 在 Manager 开始创建操作前允许为空；非空后需要全局唯一。SQLite、MySQL 和 PostgreSQL 使用来源实现的唯一索引，SQL Server 使用带 uuid <> '' 条件的唯一索引，从而同时支持多个尚未分配运行时 UUID 的排队记录。

迁移还写入默认 Dev Container 模板。模板插入与表创建属于同一来源迁移，使新安装和从分叉点升级得到相同初始配置。

升级行为

数据库版本 365 表示最后完成的迁移是 364，进入 self 时会执行本项并把版本推进到 366，随后执行 Pages 366。明确由 Codespace PR 建立、已经处于版本 366 的数据库具有相同的迁移 365 含义，可以直接执行 Pages 366。
